# HP Lift — Studieplan för Högskoleprovet

Interaktiv 8-veckorsplan för höstens Högskoleprov. Anpassad för dig som är stark på kvantitativt och engelska men behöver lyfta svenska verbala (ORD, LÄS, MEK).

## Kom igång

```bash
npm install
npm run build
npm start
```

Öppna [http://127.0.0.1:43123](http://127.0.0.1:43123).

För lokal utveckling med hot reload: `npm run dev` (samma port).

## Vad appen innehåller

- Personlig strategi utifrån tidigare resultat (kvant 1,4 / verbal 1,0)
- Genomgång av varje delprov med metoder och veckomål
- Daglig studiemall och konkret läslista (sakprosa/essä för ORD & LÄS)
- 8-veckorsplan (bas → teknik → fullprov → finish) med checklista som sparas i webbläsaren
- Länkar till gamla högskoleprov

## Scripts

- `npm run dev` — utvecklingsserver
- `npm run build` — produktionsbygge
- `npm run start` — kör byggt resultat
- `npm run lint` — ESLint
